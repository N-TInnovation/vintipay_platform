Instruções de Integração

Para configurar sua integração, siga estas etapas:

  1. Selecione o tipo de aplicação que deseja integrar.
  2. Obtenha as credenciais de API necessárias do serviço que deseja conectar.
  3. Preencha todos os campos obrigatórios com as informações corretas.
  4. Clique em "Salvar" para ativar a integração.

Se precisar de ajuda, consulte nossa documentação ou entre em contato com o suporte.
